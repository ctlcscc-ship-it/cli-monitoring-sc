# CLI Monitoring – SC Division Control Desk

GitHub Pages deployment package for the CLI Monitoring application.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `cli-monitoring-sc`.
2. Upload `index.html`, `.nojekyll`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. GitHub will publish the site at the repository Pages URL.

The application is a static HTML application. Its current data storage/backup behavior remains browser-local unless a backend/database is added later.
